# Product Launch Enablement Example

## Use Case

Internal rollout of a product release that changes seller behavior.

## Inputs

- `release-notes.md`
- `launch-context.md`

Good context includes:
- audience and impacted teams
- launch date
- rollout model
- risks and commercial implications

## Example Prompt

```text
Use $product-launch-enablement with release-notes.md and launch-context.md.
Build a field-ready enablement package for AEs, SEs, and managers.
Include readiness gates, talk-track updates, FAQ themes, and a reinforcement plan.
```

## Expected Output Shape

- Launch tier and readiness matrix
- Internal launch narrative and FAQ
- Talk-track and objection updates
- Training and reinforcement plan
- Go/no-go readiness checklist
