# Manager Coaching Cadence Example

## Use Case

Design a lightweight weekly coaching rhythm for frontline managers.

## Inputs

- `team-context.md`
- `current-coaching-pains.md`
- optional `revenue-enablement-context.md`

Useful context includes:
- team type and segment
- manager span and time constraints
- existing inspection rhythms
- desired behavior changes

## Example Prompt

```text
Use $manager-coaching-cadence with team-context.md and current-coaching-pains.md.
If revenue-enablement-context.md exists, read it first.
Return a weekly cadence, manager agenda, observation loop, and monthly trend review pattern.
```

## Expected Output Shape

- Coaching objective and design principles
- Weekly cadence
- Manager agenda and prompts
- Observation and commitment tracking loop
- Monthly review and escalation guidance
