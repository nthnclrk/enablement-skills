# Revenue Enablement Context Example

## Use Case

Create the shared context artifact that improves downstream skill quality.

## Inputs

- `company-notes.md`
- `gtm-notes.md`
- `product-notes.md`

High-value context includes:
- ICP and segments
- personas and stakeholders
- sales stages and qualification rules
- packaging and pricing basics
- common objections and competitors
- current initiatives and priorities

## Example Prompt

```text
Use $revenue-enablement-context with company-notes.md, gtm-notes.md, and product-notes.md.
Return a reusable enablement context that downstream skills can consume without re-asking for baseline information.
```

## Expected Output Shape

- Company and GTM overview
- ICP and persona map
- sales-stage and qualification model
- packaging, proof, and objection context
- current priorities and open assumptions
