# Talk Track Builder Example

## Use Case

Create a live discovery talk track for a specific persona and stage.

## Inputs

- `message-inputs.md`
- optional `revenue-enablement-context.md`
- optional positioning or objection assets

Good input context includes:
- audience and persona
- deal stage
- objective of the conversation
- likely objections
- approved claims or proof points

## Example Prompt

```text
Use $talk-track-builder with message-inputs.md.
If revenue-enablement-context.md, positioning, or objection assets exist, read them first.
Return a natural-sounding discovery talk track with branch paths, proof cues, and objection pivots.
```

## Expected Output Shape

- Conversation goal and audience
- Primary talk track
- Branch paths or pivots
- Proof guidance
- Landmines and caveats
