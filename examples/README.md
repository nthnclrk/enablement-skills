# Example Packs

These examples show how to use the skills on small, realistic, sanitized datasets.

Each upgraded pack includes:

- input fixtures that are sufficient for the promised analysis
- a natural user prompt that does not force a particular skill
- a short expected-output excerpt or review checklist
- explicit handling for missing, stale, or conflicting evidence

All company names, people, and data are fictional. The expected excerpts demonstrate quality and reasoning; they are not full golden outputs.

## How To Use A Pack

1. Open the pack directory.
2. Give the listed fixture files and prompt to an agent with this repository installed.
3. Compare the response with the pack's excerpt or checklist.
4. Check that uncertainty is preserved instead of silently repaired.
