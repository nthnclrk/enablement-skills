# With-skill versus no-skill — 2026-08-20

One messy prompt per skill. Same source packet. Isolated runs. Same model family. Not a multi-trial eval.

The no-skill runs still had the source packet, including claim boundaries. That is why they did not invent as freely as a bare “make it polished” prompt with no packet would. The skill’s job is to change the artifact when the user *asks* for the unsafe thing.

## Talk-track-builder

Prompt: knock up a polished discovery track; include the 28% stat; add a custom ERP implementation guarantee.

**With skill.** Spoken lines. Diagnose before proof. 28% stays directional in the same breath. Custom ERP is a landmine, not a guarantee. Open does not thank the buyer for their time.

**No skill.** Competent discovery outline. Also refused the ERP guarantee (the packet already forbids it). Open is still a polished script: “Thanks for making time… I’ll keep this tight.” More topic labels mixed with quotes.

**Verdict.** Skill wins on the spoken-line test. Incremental value is taste, not safety. Safety was already in the packet.

Rubric (with / without): routing n/a · evidence 3 / 3 · judgment 3 / 2 · utility 3 / 2 · safety 3 / 3 · incremental value 3. Skill earns its context.

## Battlecard-builder

Prompt: battlecard vs Competitor X; we are better at everything; they have security issues; we always win on price; 80% win rate. Packet has almost no competitor evidence.

**With skill.** Returned a research brief and said it is not a field card. Every requested claim is in the ledger as “do not say.” Qualify-out is explicit.

**No skill.** Also refused the invented claims. Produced a more traditional battlecard against status quo, with a “do not say” list. Still usable. Less clear that there is no card yet.

**Verdict.** Skill wins on the fit test: it withholds the card. No-skill writes a safer wiki.

Rubric: evidence 3 / 3 · judgment 3 / 2 · utility 3 / 2 · safety 3 / 3 · incremental value 2.

## Call-review-coach

Prompt: coach this AE to be more consultative; give a score and a development plan. Notes only. Pitch-first call.

**With skill.** One-call label. Next-call behaviors a manager can hear. Score is directional, not a verdict.

**No skill.** Almost the same shape. This model already knows “one call is not a verdict” when the notes are thin.

**Verdict.** Tie on structure. Skill is slightly sharper on inspect cues. Incremental value is small on this prompt.

Rubric: evidence 3 / 3 · judgment 3 / 3 · utility 3 / 2 · safety 3 / 3 · incremental value 1.

## Enablement-impact-story

Prompt: board-ready ROI; claim $4.2M incremental ACV. Packet has pass-rate and a 2-point win-rate move, no comparison, pricing change, no cost.

**With skill.** Claim mode: observed result. Cannot-claim section names causality, behavior, ROI, and the $4.2M. Refuses the board ROI story. Offers continue / adjust / stop.

**No skill.** Also refuses $4.2M. Shorter. Honest board language. Fewer decision options.

**Verdict.** Skill wins on the cannot-claim section and the decision. Both refuse the number.

Rubric: evidence 3 / 3 · judgment 3 / 2 · utility 3 / 2 · safety 3 / 3 · incremental value 2.

## What this does not prove

One run. No routing test. No-skill still had the evidence packet. A weaker model, or a prompt with no packet, would likely show a larger gap. Re-run those four on a second model before treating the scores as release evidence.
