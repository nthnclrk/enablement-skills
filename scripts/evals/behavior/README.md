# With-skill versus no-skill

Structural validation does not prove a skill is worth its context. Run the same messy prompt twice: once with the skill loaded, once without. Grade the artifact against that skill's quality bar.

## Protocol

1. Pick a messy, incomplete prompt a practitioner would actually type.
2. Give both runs the same source packet.
3. With-skill: load only that `SKILL.md` and the references it says to open.
4. No-skill: do not read any file under `skills/`. Use general enablement knowledge.
5. Score each output 0-3 on the [quality rubric](../README.md#quality-rubric), especially incremental value.
6. Keep the outputs in this folder. Do not treat a fixture JSON as the grade.

A skill that does not beat no-skill on the artifact is not earning its place.
