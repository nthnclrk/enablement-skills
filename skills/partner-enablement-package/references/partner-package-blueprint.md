# Partner Enablement Package Blueprint

Use this blueprint to structure partner enablement assets and execution.

## Core Package Components

- partner ICP and ideal opportunity profile
- partner talk track and value narrative
- qualification and discovery guidance
- objection and competitive handling guide
- deal support and escalation map
- certification checklist and assessment criteria

## Partner Archetype Matrix

Define package variations by archetype:

- referral partner
- reseller partner
- services or implementation partner
- strategic alliance partner

For each archetype, specify expected motion, support depth, and target outcomes.

## Co-Sell Rules Minimum

- lead registration and ownership rule
- account conflict and escalation rule
- technical support boundary
- commercial approval thresholds

## Approved Source Asset Map

Track each reusable asset with:

- asset name and owner
- approved audience (`partner-safe` or `internal-only`)
- allowed use cases
- last-reviewed date
- escalation owner for exceptions

## Rollout Cadence Minimum

- kickoff training
- first 30-day office hours
- monthly enablement refresh
- quarterly performance and package update review
