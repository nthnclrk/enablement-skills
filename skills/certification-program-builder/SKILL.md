# Certification Program Builder

Design certification that evaluates real role competence with consistent scoring.

## Confirm Inputs First

Confirm:

- Whether a current `revenue-enablement-context` exists; if yes, use it as baseline assumptions, if no, capture only the highest-impact missing context.
- Role and capabilities to certify
- Certification purpose and stakes
- Pass/fail threshold and retake policy
- Assessor group and available evidence sources
- Time available for evaluation

If important items are missing, ask the minimum needed to define fair scoring.

## Read The Right Reference

Read [references/certification-scoring-rules.md](references/certification-scoring-rules.md) before writing the rubric.

## Default Workflow

1. Define certification scope by capability, not by content completion.
2. Build rubric dimensions with behavioral indicators per score band.
3. Define evidence types and minimum proof needed to pass.
4. Write evaluation prompts and practical scenarios.
5. Set pass/fail logic, retake guardrails, and recertification cadence.
6. Add assessor anti-bias prompts, calibration workflow, and drift checks.
7. Produce certification pack and scoring guide.

## Tool Notes

- Keep certification workflow tool-agnostic.
- If requested, map rubric and score capture to the user's existing docs or spreadsheet stack.

## Output Contract

Default output includes:

- Certification blueprint
- Scoring rubric with behavior anchors
- Evaluation prompt and scenario set
- Pass/fail and retake rules
- Recertification cadence and scope rules
- Assessor calibration plan

## Quality Bar

- Rubric measures observable behavior, not vague confidence.
- Two assessors should produce similar scores on the same evidence.
- Pass criteria are defensible for manager and leadership review.
- Certification process includes anti-bias safeguards and documented recertification logic.
- Certification is practical to run repeatedly.
