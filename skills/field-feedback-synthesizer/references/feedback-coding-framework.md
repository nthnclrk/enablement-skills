# Feedback Coding Framework

Use this framework to code multi-source field feedback consistently.

## Record Schema

| Field | Description |
| --- | --- |
| Source type | Call transcript, manager note, survey, CRM note |
| Date | Capture date |
| Segment | Market segment |
| Persona | Buyer or user persona |
| Stage | Funnel or lifecycle stage |
| Raw statement | Verbatim excerpt |
| Theme tag | Normalized issue category |
| Severity | Low, Medium, High |
| Business impact | Revenue, cycle time, conversion, retention |
| Confidence | High, Medium, Low |

## Theme Taxonomy Starter

- Message clarity
- Product fit gap
- Competitive pressure
- Pricing friction
- Proof deficit
- Process friction
- Implementation risk

## Confidence Rules

- `High`: repeated across multiple independent sources.
- `Medium`: repeated in one source class with clear examples.
- `Low`: isolated signal or anecdotal statement.

## Evidence vs Interpretation

- Evidence: direct quote, observed behavior, measurable outcome.
- Interpretation: inferred cause, strategic hypothesis, recommendation.

Always label interpretation explicitly.
