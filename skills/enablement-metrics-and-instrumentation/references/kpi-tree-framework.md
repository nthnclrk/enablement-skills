# KPI Tree Framework

Use this structure for enablement measurement design.

## 1) Outcome Layer

Business outcomes, for example:

- Win rate
- Sales cycle length
- Expansion rate

## 2) Behavior Layer

Field behaviors expected to drive outcomes, for example:

- Discovery quality
- Talk-track adoption
- Manager coaching consistency

## 3) Activity Layer

Enablement activities intended to change behavior, for example:

- Program participation
- Practice completion
- Certification completion

## 4) Metric Definition Rules

For each metric define:

- Metric name
- Formula
- Data source
- Owner
- Refresh cadence
- Baseline and target

## 5) Interpretation Rules

- Avoid claiming direct causality from one metric alone.
- Use trend direction with confidence labels when data is incomplete.
- Pair lagging outcomes with leading behavior indicators.
