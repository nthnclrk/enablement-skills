# Manager Coaching Cadence

Build a manager coaching rhythm that drives continuous behavior improvement.

## Confirm Inputs First

Confirm:

- If a current revenue-enablement-context exists, use it first for ICP, stage, and message expectations. If not, ask for only the highest-impact missing context.
- Team role mix and performance context
- Top 2-3 coaching priorities tied to observable behaviors
- Existing manager meeting cadence and current inspection rhythm
- Available evidence sources and quality (call data, deal reviews, CRM, manager notes)
- Manager span, capacity limits, and escalation constraints
- Team type (SMB velocity, mid-market, enterprise, post-sale) for cadence tailoring

If key data is missing, ask for only what is needed to design a workable cadence.

## Read The Right Reference

- Read [references/manager-coaching-cadence-template.md](references/manager-coaching-cadence-template.md) before producing final cadence assets.

## Default Workflow

1. Define the top 2-3 behaviors to improve and tie each to observable inspection signals.
2. Choose a cadence variant by team type (SMB, mid-market, enterprise, post-sale) from the reference.
3. Build the weekly loop with time budgets:
   inspect evidence, run focused coaching, capture rep commitments, schedule follow-up checks.
4. Create a manager agenda template and observation log template.
5. Add commitment tracking with owner, due date, verification signal, and carry-forward status.
6. Build a monthly trend review that separates recurring skill gaps from pipeline/process issues.
7. Define escalation triggers for persistent underperformance and support actions.
8. Produce a rollout plan managers can run immediately with minimal setup.

## Tool Notes

- Keep coaching cadence tool-agnostic.
- If call intelligence or CRM is available, use those systems as evidence inputs but keep the workflow usable without them.
- If evidence quality is low, reduce conclusion strength and increase direct observation frequency before major interventions.

## Output Contract

Default output includes:

- Weekly coaching cadence schedule by manager
- Session agenda template and coaching-question prompts
- Observation log template for calls/deals/behavior checkpoints
- Rep commitment tracker with due dates and verification signals
- Monthly trend review template and interpretation guidance
- Escalation guidance for persistent gaps
- Implementation notes for first 30 days

## Quality Bar

- Cadence is sustainable for real manager workloads.
- Coaching targets behavior change, not generic feedback.
- Follow-up is explicit so sessions connect over time.
- Output can be run immediately with minimal setup.
- Distinguish skill/coaching issues from process, territory, or pipeline-health issues.
