# Release Note Transformation Guide

Use this guide to convert product-centric release notes into seller-ready updates.

## Change Classification

Classify each release item by:

- `type`: new capability, enhancement, fix, deprecation, policy change
- `impact`: high, medium, low
- `audience`: AE, AM, CSM, SE, support
- `timing`: immediate, scheduled, phased rollout

## Seller Translation Template

For each relevant change, produce:

- what changed
- why customers should care
- when to mention it in the sales cycle
- what to avoid saying
- known caveats or eligibility constraints

## FAQ Minimum

Include:

- expected customer questions
- migration or adoption risks
- competitive implications
- escalation path for unresolved edge cases

## Distribution Formats

Prepare one short format and one detailed format:

- short: chat or email digest
- detailed: wiki or playbook update with linked references
